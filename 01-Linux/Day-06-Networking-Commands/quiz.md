# 📝 Quiz (10 Questions) — Linux Networking Commands

## Questions
1. Which command displays IP addresses?
2. Which command tests connectivity?
3. Which command retrieves HTTP headers?
4. Which command downloads files?
5. Which command shows listening ports?
6. Which command displays the hostname?
7. Which command performs a basic DNS lookup?
8. Which command provides detailed DNS information?
9. Which command shows the routing table?
10. Which command traces the network path?

## Answers
1. `ip addr`
2. `ping`
3. `curl -I`
4. `wget`
5. `ss -tuln`
6. `hostname`
7. `nslookup`
8. `dig`
9. `ip route`
10. `traceroute`
